## Проблемы по важности

### High
1. **Нет аутентификации ни на одном эндпоинте** + `CORS allow_origins=["*"]` вместе с `allow_credentials=True` (`backend/app/main.py:27-33`). Любой может создавать/удалять алерты и позиции, запускать тяжёлые скрины. Фикс: API-key/JWT, явный список origin.
2. **Дорогие операции через GET без защиты:** `GET /api/v1/screener/cron/run` (`routes.py:188`) синхронно запускает полный скрининг (~100 секунд, сотни запросов к Binance) — легко DoS и бан IP на бирже. Фикс: токен (CRON_SECRET) + POST.
3. **CVE в зависимостях backend** (starlette 0.27.0 — множественные, fastapi 0.104.1, python-multipart 0.0.6 — DoS/ReDoS, anyio, python-dotenv). Фикс: поднять fastapi/starlette/python-multipart/anyio (fastapi ≥0.115, python-multipart ≥0.0.31, starlette по совместимости), прогнать smoke заново.
4. **Нет тестов** — для проекта со статистикой/деньгами (net-edge, FDR, Kalman) регрессии неотлавливаемы.
5. **Незакоммиченная работа:** 12 файлов + `kalman.py` вне git; PROGRESS.md заявляет «Done», но коммита нет. Риск потери. Ошибки `tsc` (`funding_bps_per_8h`) показывают, что `api.ts` не синхронизирован с `ScreenerSettings.tsx` (пункт «surface controls» заявлен выполненным, но тип не добавлен).

### Medium
6. **`GET /screener/debug/db`** (`routes.py:39`) отдаёт драйвер, хост, порт, имя БД, пользователя — информационная утечка (пароль не отдаёт). Удалить или закрыть.
7. **Утечка деталей ошибок:** 27 мест `detail=f"...{str(e)}"` в роутерах (`routes.py:205,229,507,1065,1146` и др.).
8. **Нет rate limit / лимитов размера тела.**
9. **Docker/compose:** Redis (6379) и Postgres (5432, пароль `datalayer/datalayer`) публикуются на 0.0.0.0; контейнер backend от root; frontend в compose — dev-сервер (`npm ci && vite`) под `node:18-alpine` (EOL); нет healthcheck; в `frontend` Dockerfile — nginx-config через `echo`.
10. **Качество результатов:** в UI beta = 70, 544 (SOL/DOGE 544.76), HURST «—» почти везде, средний Hurst 0.005 — регрессия на нормированных ценах/лог-ценах нужна; такие пары — артефакты масштаба.
11. **Live monitor нестабилен:** снапшот считается синхронно в запросе, тянет 5м-свечи для 20 пар (500 из 864 запрошенных баров — лимит ccxt без пагинации), пары с <60 барами молча отбрасываются; на сервере вернулся 0 пар. Блокирует event loop.
12. **Алерты/позиции не проверяют `pair_id`** (создан алерт на несуществующую пару — 200).

### Low
13. `tsc`/`mypy`/`ruff` — ошибки (см. таблицу); `datetime.utcnow()` (29), blind `except` (88).
14. Frontend bundle 749 кБ без code-split.
